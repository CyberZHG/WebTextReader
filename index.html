      免责声明与隐私说明

      • 本网页是托管在 GitHub Pages 上的纯静态页面，没有后端服务器，也不收集任何统计或分析数据。
      • 你粘贴的文本、上传的文件、阅读进度、书签、设置、统计和成就都只保存在当前浏览器本地（localStorage 与 IndexedDB），不会上传到任何服务器。
      • 朗读由浏览器自带的 Web Speech API 完成。名称带“在线”的语音可能由浏览器厂商的云端服务合成，此时朗读内容会发送给浏览器厂商，这不受本网页控制；如有顾虑，请选择本地语音。
      • 清除浏览器的网站数据会删除以上所有内容，请通过“更多设置 → 数据备份”定期导出。导出的备份文件同样只保存在你自己的设备上。
      • 本工具按原样提供，不对使用中产生的任何问题承担责任。请确保你有权朗读所使用的内容。
